# Dashboard Builder Agent

## Overview
The Dashboard Builder Agent is the final integration project of my Wayfair AI Agent Engineering Externship. Built using **n8n and JavaScript**, this workflow automatically combines consumer trend research and competitor analysis into a unified, HTML-based market intelligence dashboard.

## Objective
To streamline market intelligence reporting by transforming separate research reports into a centralized dashboard that supports data-driven product, pricing, and marketing decisions for Wayfair's Rugs category.

## How It Works
1. **Upload Reports:** Users select a product category and upload HTML reports generated by the Consumer Trend Discovery and Competitor Monitoring agents.
2. **Extract Data:** JavaScript parses the reports to retrieve market metrics, consumer preferences, competitor pricing, and strategic recommendations.
3. **Generate Dashboard:** Extracted data is dynamically integrated into an HTML dashboard template.
4. **Prepare Output:** The completed dashboard is converted into a downloadable HTML file.

## Key Features
- **Consumer Trend Analysis:** Displays market growth metrics, emerging consumer segments, color palettes, and product preferences.
- **Competitive Intelligence:** Compares Wayfair, Amazon, and Walmart across pricing, product offerings, and competitive positioning.
- **Strategic Recommendations:** Consolidates market opportunities, potential risks, and recommended actions.
- **Automated Report Integration:** Combines two independently generated HTML reports into one structured dashboard.

## Tools & Technologies
- **n8n** – Workflow automation
- **JavaScript** – HTML parsing, data extraction, and dashboard generation
- **HTML / JSON** – Dashboard presentation and workflow configuration
- **HTTP Requests** – Retrieval of the dashboard template
