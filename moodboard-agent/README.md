# Moodboard AI Agent

## Summary

An AI agent that generates interior design moodboards using Google's Gemini model and AI image generation.

## Technologies

- n8n
- Google Gemini
- Hugging Face Inference API
- Prompt Engineering
- Workflow Automation

## Workflow

1. User enters preferences.
2. Gemini rewrites the prompt for image generation.
3. Prompt is cleaned and formatted.
4. Hugging Face generates a moodboard image.
5. Output file is renamed automatically.

## Example Prompt

> "Round jute rug, Scandinavian living room, neutral palette, warm wood, soft daylight."
